# NowCoder 代码索引

本目录按比赛场次归档。源文件统一使用 `题目编号_题目名字.cpp` 命名；每个文件头记录比赛、题目链接、完成状态和算法标签。

## 状态说明

- `已通过`：牛客账号的团队状态显示该题已经通过。
- `未通过`：牛客账号的团队状态显示该题尚未通过。
- `待验证`：已有完整实现，但暂时没有可归属于该本地源码的在线评测记录。
- `未完成`：仓库文件只有框架、部分实现或实现与题意不符；即使账号已通过，也不能把该文件视为 AC 代码。

最近状态核对日期：2026-08-21。多人比赛只记录仓库已有源码；团队中其他成员完成、而本地没有对应源码的题目不纳入个人实现记录。
