# 算法竞赛 DP 复习笔记

动态规划的重点不是背转移式，而是根据题意设计状态，并让计算顺序满足状态依赖。

配套代码手册：[DP 模板总复习](../../Templates/DP模板总复习.md)。

## 一、做 DP 的固定思考顺序

遇到一道 DP 题，依次回答下面六个问题：

1. **状态是什么？** `dp[...]` 表示什么？
2. **状态需要记录哪些信息？** 哪些信息会影响未来转移？
3. **从哪里转移？** 当前状态能由哪些更小的状态得到？
4. **如何合并答案？** 使用 `max`、`min`、求和还是逻辑或？
5. **如何初始化？** 哪些是合法起点，哪些状态不可达？
6. **按什么顺序计算？** 如何保证依赖的状态已经求出？

最重要的原则是：

> DP 状态必须保存未来转移需要的信息。

例如，LIS 不能只记录“前 `i` 个数中的最长长度”，因为加入新数时还需要知道子序列末尾是什么。因此应定义：

```cpp
dp[i] = 必须以 a[i] 结尾的 LIS 长度
```

### 初始化的语义

| 问题类型 | 常见初值 | 含义 |
| --- | --- | --- |
| 求最大值 | `-INF` | 状态不可达 |
| 求最小值 | `INF` | 状态不可达 |
| 可达性 | `false` | 当前还不可达 |
| 方案计数 | `0` | 当前没有方案 |
| 合法起点 | `0`、`1` 或 `true` | 空方案或起始状态 |

`0` 可能是合法答案，而 `INF`、`-INF` 表示状态根本不可达，两者不能混用。

从不可达状态转移前还应先判断，避免执行 `INF + cost` 或 `-INF + value`。

## 二、基础线性与路径 DP

### 1. 不选相邻元素

定义：

```cpp
dp[i] = 前 i 个数中，不选相邻元素能够获得的最大和
```

第 `i` 个数有选和不选两种决策：

```cpp
dp[i] = max(
    dp[i - 1],
    dp[i - 2] + a[i]
);
```

也可以显式记录第 `i` 个数是否被选：

```cpp
dp[i][0] = 前 i 个数中，第 i 个不选时的最大和
dp[i][1] = 前 i 个数中，第 i 个被选时的最大和
```

```cpp
dp[i][0] = max(dp[i - 1][0], dp[i - 1][1]);
dp[i][1] = dp[i - 1][0] + a[i];
```

答案为：

```cpp
max(dp[n][0], dp[n][1]);
```

### 2. Frog 跳石头

定义：

```cpp
dp[i] = 到达第 i 块石头的最小花费
```

只能跳一格或两格：

```cpp
dp[i] = min(
    dp[i - 1] + abs(h[i] - h[i - 1]),
    dp[i - 2] + abs(h[i] - h[i - 2])
);
```

最多跳 `k` 格：

```cpp
for (int j = 1; j <= k && i - j >= 0; j ++){
    dp[i] = min(
        dp[i],
        dp[i - j] + abs(h[i] - h[i - j])
    );
}
```

复杂度为 `O(nk)`。如果转移区间更规则，可以继续考虑单调队列等优化。

### 3. 网格 DP

只能向右、向下移动时，最大路径权值可以写成：

```cpp
dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]) + a[i][j];
```

路径方案数为：

```cpp
dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
```

遇到障碍物时：

```cpp
if (grid[i][j] == '#'){
    dp[i][j] = 0;
}
```

计数问题通常初始化：

```cpp
dp[1][1] = 1;
```

边界可以通过额外一圈哨兵或单独判断来处理。

## 三、可达性与背包 DP

### 1. 可达性 DP

每个数选或不选，判断能否凑出 `S`：

```cpp
dp[i][j] = 前 i 个数能否凑出 j
```

```cpp
dp[i][j] = dp[i - 1][j];

if (j >= a[i]){
    dp[i][j] |= dp[i - 1][j - a[i]];
}
```

初始化：

```cpp
dp[0][0] = true;
```

因为不选择任何元素时，恰好可以凑出 `0`。

### 2. 01 背包

每个物品最多选择一次：

```cpp
dp[j] = 容量不超过 j 时能够获得的最大价值
```

```cpp
for (int i = 1; i <= n; i ++){
    for (int j = W; j >= w[i]; j --){
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

容量必须倒序，防止本轮刚更新的状态再次使用同一个物品。

### 3. 完全背包

每个物品可以选择无限次：

```cpp
for (int i = 1; i <= n; i ++){
    for (int j = w[i]; j <= W; j ++){
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

容量使用正序，允许本轮刚更新的状态继续使用当前物品。

```text
01 背包   → 容量倒序 → 当前物品最多用一次
完全背包 → 容量正序 → 当前物品可以重复使用
```

### 4. “不超过容量”与“恰好达到”

如果定义为：

```cpp
dp[j] = 总重量不超过 j 时的最大价值
```

允许什么都不选时，通常可以把所有状态初始化为 `0`。

如果定义为：

```cpp
dp[j] = 总重量恰好为 j 时的最大价值
```

则应初始化：

```cpp
dp[0] = 0;
dp[1 ... W] = -INF;
```

这能区分“价值恰好为 `0`”与“该重量不可达”。

### 5. 最少元素数

定义：

```cpp
dp[i][j] = 使用前 i 个数凑出 j 所需的最少元素数
```

```cpp
dp[i][j] = dp[i - 1][j];

if (j >= a[i]){
    dp[i][j] = min(
        dp[i][j],
        dp[i - 1][j - a[i]] + 1
    );
}
```

初始化：

```cpp
dp[0][0] = 0;
dp[0][j] = INF;
```

### 6. 分组背包

每组最多选择一个物品。循环顺序应为：

```cpp
for (每一组 g){
    for (int j = W; j >= 0; j --){
        for (当前组中的每个物品 i){
            if (j >= w[i]){
                dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
            }
        }
    }
}
```

不能使用“组 → 物品 → 容量”的顺序，否则同一组后面的物品可能利用本组前一个物品刚更新的状态，导致一组选择多个物品。

## 四、序列与字符串 DP

### 1. 最长上升子序列 LIS

定义：

```cpp
dp[i] = 必须以 a[i] 结尾的 LIS 长度
```

```cpp
dp[i] = 1;

for (int j = 1; j < i; j ++){
    if (a[j] < a[i]){
        dp[i] = max(dp[i], dp[j] + 1);
    }
}
```

答案是所有结尾中的最大值：

```cpp
max(dp[i]);
```

基础复杂度为 `O(n^2)`。核心是状态必须记录结尾，才能判断新数能否接在后面。

### 2. 最长公共子序列 LCS

定义：

```cpp
dp[i][j] = s 的前 i 个字符与 t 的前 j 个字符的 LCS 长度
```

```cpp
if (s[i - 1] == t[j - 1]){
    dp[i][j] = dp[i - 1][j - 1] + 1;
} else {
    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
}
```

### 3. 最长公共子串

子串必须连续，因此状态要记录“以当前字符结尾”：

```cpp
dp[i][j] = 以 s[i - 1]、t[j - 1] 结尾的最长公共子串长度
```

```cpp
if (s[i - 1] == t[j - 1]){
    dp[i][j] = dp[i - 1][j - 1] + 1;
} else {
    dp[i][j] = 0;
}
```

答案是所有 `dp[i][j]` 的最大值，而不一定是 `dp[n][m]`。

### 4. 编辑距离

定义：

```cpp
dp[i][j] = s 的前 i 个字符变成 t 的前 j 个字符所需的最少操作数
```

字符相同时：

```cpp
dp[i][j] = dp[i - 1][j - 1];
```

字符不同时：

```cpp
dp[i][j] = min({
    dp[i - 1][j - 1] + 1, // 修改
    dp[i][j - 1] + 1,     // 插入
    dp[i - 1][j] + 1      // 删除
});
```

初始化：

```cpp
dp[0][j] = j;
dp[i][0] = i;
```

## 五、区间 DP

典型定义为：

```cpp
dp[l][r] = 区间 [l, r] 的最优答案
```

因为大区间依赖小区间，所以遍历顺序通常是短区间到长区间：

```cpp
for (int len = 2; len <= n; len ++){
    for (int l = 1; l + len - 1 <= n; l ++){
        int r = l + len - 1;

        for (int k = l; k < r; k ++){
            // 转移
        }
    }
}
```

### 1. 石子合并

定义：

```cpp
dp[l][r] = 把区间 [l, r] 合并成一堆的最小代价
```

枚举最后一次合并的分割点 `k`：

```cpp
dp[l][r] = min(
    dp[l][r],
    dp[l][k] + dp[k + 1][r] + sum(l, r)
);
```

其中 `sum(l, r)` 是最后把左右两堆合并的代价。

```cpp
dp[i][i] = 0;
```

朴素复杂度为 `O(n^3)`。

### 2. 最长回文子序列

定义：

```cpp
dp[l][r] = 区间 [l, r] 中最长回文子序列的长度
```

```cpp
if (s[l] == s[r]){
    dp[l][r] = dp[l + 1][r - 1] + 2;
} else {
    dp[l][r] = max(dp[l + 1][r], dp[l][r - 1]);
}
```

初始化：

```cpp
dp[i][i] = 1;
```

## 六、状态压缩 DP

使用二进制 `mask` 表示集合。

```cpp
(mask >> i) & 1       // 判断第 i 位
mask | (1 << i)       // 加入 i
mask & ~(1 << i)      // 删除 i
mask ^ (1 << i)       // 翻转 i
```

典型状态：

```cpp
dp[mask] = 已经选择 mask 中元素时的最优答案
```

加入一个尚未选择的元素：

```cpp
if (!((mask >> i) & 1)){
    int newMask = mask | (1 << i);
    dp[newMask] = min(dp[newMask], dp[mask] + cost);
}
```

常见复杂度：

```text
只枚举 mask              O(2^n)
mask + 枚举一个元素      O(n * 2^n)
mask + 枚举所有子集      O(3^n)
```

枚举 `mask` 的所有非空子集：

```cpp
for (int sub = mask; sub; sub = (sub - 1) & mask){
}
```

## 七、DAG DP

有向无环图上的 DP 必须按照拓扑序转移。

若存在边 `u -> v`：

```cpp
dp[v] = max(dp[v], dp[u] + w); // 最长路
dp[v] = min(dp[v], dp[u] + w); // 最短路
dp[v] += dp[u];                // 路径计数
```

不按拓扑序时，`dp[u]` 可能尚未更新完整，就被提前用于更新后继节点。

## 八、树形 DP

树没有环，通常先 DFS 儿子，再用儿子的答案更新父亲，即后序处理。

### 1. 父子不能同时选择

```cpp
dp[u][0] = 不选 u 时，u 子树能够获得的最大价值
dp[u][1] = 选择 u 时，u 子树能够获得的最大价值
```

```cpp
dp[u][0] += max(dp[v][0], dp[v][1]);
dp[u][1] += dp[v][0];
```

初始化：

```cpp
dp[u][0] = 0;
dp[u][1] = a[u];
```

答案：

```cpp
max(dp[root][0], dp[root][1]);
```

### 2. 树上直径 DP

定义：

```cpp
dp[u] = 从 u 向子树方向延伸的一条最长链
```

处理儿子 `v` 时：

```cpp
ll len = dp[v] + w;
```

维护从 `u` 向下的最长链 `mx1` 和次长链 `mx2`：

```cpp
ans = max(ans, mx1 + mx2);
dp[u] = mx1;
```

向父亲只能传递一条链，不能传递已经在 `u` 处分叉的两条链。

### 3. 树上背包

定义：

```cpp
dp[u][j] = u 子树中恰好选择 j 个节点的最大价值
```

合并儿子 `v`：

```cpp
dp[u][j + k] = max(
    dp[u][j + k],
    dp[u][j] + dp[v][k]
);
```

含义是父亲当前部分选择 `j` 个，再从儿子子树选择 `k` 个。

如果题目规定“只要选择 `u` 子树中的点，就必须选择 `u`”，可以约定：

```text
dp[u][0]       = 整个子树都不选
dp[u][j], j>=1 = 选择 j 个点并且必须包含 u
```

合并儿子的非空方案时，要保证父亲状态已经选择了 `u`。

### 4. 换根 DP：距离和

要求每个点到其他所有点的距离和。

第一遍 DFS 求：

```cpp
sz[u] = u 的子树大小
```

并求出某个根的答案：

```cpp
ans[root] = sum(dep[i]);
```

从父亲 `u` 换根到儿子 `v`：

```cpp
ans[v] = ans[u] - sz[v] + (n - sz[v]);
```

化简为：

```cpp
ans[v] = ans[u] + n - 2 * sz[v];
```

因为 `v` 子树内每个点的距离减少 `1`，其他点的距离增加 `1`。

### 5. down / up 换根

```cpp
down[u] = 从 u 向子树方向走的最远距离
up[u]   = 从 u 向父亲方向走的最远距离
```

最终：

```cpp
ans[u] = max(down[u], up[u]);
```

给儿子 `v` 计算 `up[v]` 时，不能再次使用来自 `v` 的向下链，否则会走回头路。因此需要维护：

```text
mx1 = 最长向下链
mx2 = 次长向下链
id1 = 最长链来自哪个儿子
```

```cpp
ll best;
if (id1 == v){
    best = mx2;
} else {
    best = mx1;
}

up[v] = 1 + max(up[u], best);
```

## 九、概率与期望 DP

### 1. 概率 DP

前 `i` 次独立实验恰好成功 `j` 次：

```cpp
dp[i][j] = 前 i 次实验恰好成功 j 次的概率
```

单次成功概率为 `p`：

```cpp
dp[i][j]
= p * dp[i - 1][j - 1]
+ (1 - p) * dp[i - 1][j];
```

初始化：

```cpp
dp[0][0] = 1;
```

### 2. 期望 DP

核心公式：

```text
当前期望 = 当前操作代价 + Σ(转移概率 × 后续期望)
```

例如，每一步花费 `1`，以 `0.5` 概率到 `i + 1`，以 `0.5` 概率到 `i + 2`：

```cpp
dp[i] = 1 + 0.5 * dp[i + 1] + 0.5 * dp[i + 2];
```

如果有概率留在原地：

```text
0.2 留在 i
0.3 到 i + 1
0.5 到 i + 2
```

则：

```cpp
dp[i]
= 1
+ 0.2 * dp[i]
+ 0.3 * dp[i + 1]
+ 0.5 * dp[i + 2];
```

将自身项移到左侧：

```cpp
dp[i] = (
    1
    + 0.3 * dp[i + 1]
    + 0.5 * dp[i + 2]
) / 0.8;
```

出现 `dp[i]` 自身时必须移项，不能直接递推。

## 十、数位 DP

典型搜索状态：

```cpp
dfs(pos, ..., limit, started)
```

```text
pos      当前处理的位置
limit    当前前缀是否仍贴着上界
started  是否已经出现有效数字
```

当前位能够填写的最大数字：

```cpp
int up = limit ? digit[pos] : 9;
```

转移：

```cpp
bool nxt_limit = limit && (d == digit[pos]);
bool nxt_started = started || (d != 0);
```

常见附加状态：

```text
数位和等于 S     → sum
恰好有 k 个 7    → cnt
不能连续两个 1   → last
数字模 m 等于 0  → mod
```

```cpp
int nxt_sum = sum + d;
int nxt_mod = (mod * 10 + d) % m;
```

记忆化一般缓存不受上界约束的标准状态：

```cpp
if (!limit && memo[...] != -1){
    return memo[...];
}
```

如果前导零会影响答案，`started` 也必须进入记忆化状态。

## 十一、状态机 DP

当两个局面未来允许的操作不同，即使当前答案看起来相同，也应该拆成不同状态。

### 1. 基础股票模型

```cpp
dp[i][0] = 第 i 天结束时不持股的最大收益
dp[i][1] = 第 i 天结束时持股的最大收益
```

```cpp
dp[i][0] = max(
    dp[i - 1][0],
    dp[i - 1][1] + a[i]
);

dp[i][1] = max(
    dp[i - 1][1],
    dp[i - 1][0] - a[i]
);
```

初始化：

```cpp
dp[1][0] = 0;
dp[1][1] = -a[1];
```

### 2. 带冷冻期

```cpp
dp[i][0] = 普通不持股
dp[i][1] = 持股
dp[i][2] = 今天刚卖出
```

```cpp
dp[i][0] = max(dp[i - 1][0], dp[i - 1][2]);
dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - a[i]);
dp[i][2] = dp[i - 1][1] + a[i];
```

“普通不持股”和“今天刚卖出”未来能否立即买入不同，因此必须拆开。

### 3. 限制交易次数

最多进行 `k` 次交易时，可以增加交易次数这一维：

```cpp
dp[i][j][0 / 1]
```

如果规定买入时交易次数增加 `1`：

```cpp
dp[i][j][1] = max(
    dp[i - 1][j][1],
    dp[i - 1][j - 1][0] - a[i]
);

dp[i][j][0] = max(
    dp[i - 1][j][0],
    dp[i - 1][j][1] + a[i]
);
```

也可以让卖出时次数增加，但状态定义和转移必须始终一致。

## 十二、常见 DP 优化

### 1. 滚动数组

如果 `dp[i][j]` 只依赖上一行和当前行，可以压缩为 `dp[j]`。

例如：

```cpp
dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
```

压缩后：

```cpp
dp[j] = dp[j] + dp[j - 1];
```

此时必须正序更新：

```text
更新前的 dp[j]   = 上一行的状态
更新后的 dp[j-1] = 当前行左侧的状态
```

滚动数组的遍历方向仍由依赖关系决定，不能机械地固定为正序或倒序。

### 2. 前缀和优化

如果：

```cpp
dp[i] = dp[i - 1] + dp[i - 2] + ... + dp[i - k];
```

朴素复杂度为 `O(nk)`。维护：

```cpp
pre[i] = dp[0] + dp[1] + ... + dp[i];
```

即可得到：

```cpp
dp[i] = pre[i - 1] - pre[i - k - 1];
```

复杂度降为 `O(n)`。看到连续区间求和，应优先想到前缀和。

### 3. 单调队列优化

如果：

```cpp
dp[i] = max(dp[j]) + v[i];
```

并且：

```text
i - k <= j <= i - 1
```

可以用单调队列维护滑动区间内最大的 `dp[j]`。

```cpp
deque <int> q;

// 删除已经离开窗口的下标
while (q.size() && q.front() < i - k){
    q.pop_front();
}

// 使用当前窗口最优状态转移
dp[i] = dp[q.front()] + a[i];

// 维护 dp 值单调递减
while (q.size() && dp[q.back()] <= dp[i]){
    q.pop_back();
}

q.push_back(i);
```

每个下标最多进队和出队一次，复杂度为 `O(n)`。

## 十三、遍历顺序速查

| 类型 | 典型顺序 | 原因 |
| --- | --- | --- |
| 线性 DP | 从小到大 | 当前状态依赖更早位置 |
| 01 背包 | 容量倒序 | 禁止同一物品重复使用 |
| 完全背包 | 容量正序 | 允许重复使用当前物品 |
| 分组背包 | 组 → 容量倒序 → 组内物品 | 每组最多选择一个 |
| 区间 DP | 短区间到长区间 | 大区间依赖小区间 |
| DAG DP | 拓扑序 | 前驱必须先计算完整 |
| 树形 DP | DFS 后序 | 先计算儿子，再更新父亲 |
| 换根 DP | 后序一次、前序一次 | 先求子树信息，再传父侧信息 |
| 数位 DP | 从高位向低位搜索 | 当前位决定后续限制 |

遍历方向不是模板中的装饰，而是状态转移正确性的一部分。

## 十四、常见错误检查清单

写完 DP 后，按顺序检查：

1. `dp` 的每一维是否都有明确含义？
2. 状态是否保存了未来转移所需的全部信息？
3. 转移是否覆盖了所有决策，并且没有重复或越界？
4. 不可达状态是否使用了正确的 `INF` 或 `-INF`？
5. 是否从不可达状态进行了加法转移？
6. 初始状态是否代表一个真正合法的空方案或起点？
7. 遍历顺序是否保证依赖状态已经求出？
8. 题目问“恰好达到”还是“不超过”？
9. 答案是 `dp[n]`、`dp[n][m]`，还是所有状态中的最大或最小值？
10. 方案数是否需要取模？数值是否需要使用 `long long`？
11. 状态压缩或滚动数组后，是否意外使用了本轮的新状态？
12. 时间复杂度和空间复杂度是否满足数据范围？

## 十五、最终应记住的八条

1. **先定义状态，再写转移。**
2. **状态要保存未来转移需要的信息。**
3. 求最大值时不可达状态通常设为 `-INF`，求最小值时设为 `INF`。
4. `dp[0][0] = true / 1 / 0` 本质上都在定义合法起点。
5. **01 背包倒序，完全背包正序**，本质是是否允许使用本轮的新状态。
6. DP 的遍历顺序必须保证依赖状态先算好。
7. 遇到 `O(nk)` 转移时，观察它是否是区间和或区间最值，考虑前缀和、单调队列等优化。
8. 不要只背公式，要能够解释：**这个状态从哪里来，为什么不会漏，也为什么不会重复？**

复习下一步应以题目为主，把这些模型和具体限制对应起来，而不是继续机械扩展更多类型。
